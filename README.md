# Privacy Policy / 隐私政策 — ImgFlux

**Effective Date / 生效日期**: 2026-11-25

---

## English

**ImgFlux** ("the App") is a 100% offline local image format converter and compressor for Windows.

1. **No Data Collection**: The App does not collect, store, transmit, or share any personal information, usage analytics, crash telemetry, or advertising identifiers.
2. **100% Local Processing**: All image decoding, format conversion, resizing, compression, and EXIF metadata removal happen strictly on your local device. Your images are never uploaded to any remote server.
3. **No Network Access**: The App operates without requiring an internet connection and makes zero background network requests.
4. **Local File Access**: The App only accesses files and folders that you explicitly select or drag into the window, and writes converted output files to the output folder you choose without overwriting original files. Local preferences (such as default format, quality, theme, and language) are stored only on your device under your local AppData folder.
5. **Contact**: If you have any questions about this Privacy Policy, please contact `zhicong.zh@outlook.com`.

## 简体中文

**ImgFlux**（下称“本应用”）是一款完全在本地离线运行的图片格式转换与压缩工具。

1. **不收集任何数据**：本应用不收集、不存储、不传输、不共享任何个人身份信息、使用行为统计、广告标识或遥测数据。
2. **100% 本地处理**：所有图片解码、格式转换、压缩、缩放以及 EXIF 元数据清除均在您的本地设备上完成，绝不会将您的任何图片或元数据上传至云端服务器。
3. **不联网运行**：本应用无需网络连接即可使用，也不会在后台发起任何网络请求。
4. **本地文件权限说明**：本应用仅访问您主动选择或拖入窗口的图片和文件夹，并将转换结果写入您指定的输出目录（默认不覆盖原文件）。您的偏好设置（如默认格式、压缩质量、主题与语言）仅保存在本机 `AppData` 目录中。
5. **联系方式**：如对本隐私政策有任何疑问，请联系 `zhicong.zh@outlook.com`。
